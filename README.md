# Ben's Classes

Mobile-first Fall 2026 UMass Dartmouth schedule app.

## Schedule
- POM 212-01 — Business Statistics — Charlton 340
- MGT 312-02 — Legal Framework Business — Charlton 247
- ECO 232-04H — Principles Macro — Claire Carney Library 226
- ACT 211-05H — Principles of Accounting I — Charlton 248
- MKT 311-02 — Principles of Marketing — Claire Carney Library 207

Classes meet Monday, Wednesday, and Friday.

## Phone install
Publish the repository with GitHub Pages. Then open the site on your phone:
- iPhone: Safari → Share → Add to Home Screen
- Android: Chrome → menu → Add to Home screen / Install app

The service worker caches the schedule so the app can still open offline.
